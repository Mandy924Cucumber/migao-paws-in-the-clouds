# 喵跃云端 · Paws in the Clouds

一个可以直接运行、继续开发的 Godot 3D 猫咪跳跃跑酷项目。缩小的小猫沿着扑克牌、旋纹糖、彩球、糖霜饼干和礼盒组成的螺旋路线，跳向云端的庆祝蛋糕。画面采用粉、薄荷绿、奶油黄与淡紫配色，包含第三人称跟随镜头、弹性落地动画、云海、粒子效果和合成音效。

## 开始游戏

使用 **Godot 4.3 或更新的 4.x 版本**打开项目；已在 **Godot 4.7.2** 验证。

1. 在 Godot 项目管理器中导入本目录的 `project.godot`。
2. 等待首次资源导入完成，按 **F5** 运行项目。
3. 点击“开始冒险”，或在标题画面按空格。已有进度时从最近的汉堡检查站继续。

本机也可以双击 `开始游戏.command`，脚本会从“应用程序”或“下载”文件夹查找 Godot 并启动游戏。

也可以在项目目录用命令行启动。以下示例中的 `godot` 代表本机 Godot 可执行文件；macOS 可以替换为 Godot 应用内的 `Godot.app/Contents/MacOS/Godot` 完整路径。

```sh
godot --path .
```

项目使用 **Compatibility** 渲染器，面向原生桌面窗口运行。模型、装饰、图标与音效由项目代码生成；中文字体已随项目附带，运行无需下载素材或连接网络。

## 操作

| 操作 | 按键或鼠标 |
| --- | --- |
| 跳向下一块平台 | 不按方向键时按空格，自动计算跳跃方向 |
| 连续辅助跳跃 | 按住空格 |
| 自由移动、空中修正 | WASD 或方向键；按下方向键会接管辅助跳跃 |
| 自由旋转视角 | 在游戏画面中按住鼠标左键、右键或中键拖动 |
| 拉近、拉远镜头 | 鼠标滚轮 |
| 恢复第三人称自动跟随 | F |
| 回到最近检查站 | R |
| 打开、关闭猫咪衣橱 | C |
| 暂停、继续或关闭弹窗 | Esc |

普通平台会在落地后短暂停顿，再把猫咪弹起；汉堡检查站允许停留休息。辅助跳跃适合轻松探索，也可以用方向键手动挑战。衣橱打开时会暂停角色运动；窗口失去焦点时也会自动暂停。

## 路线、奖励与衣橱

完整路线共有 **43 块平台**：6 个汉堡检查站、36 块普通物品和 1 个终点蛋糕。每两个汉堡之间有 6 块普通物品；到达更高的汉堡会更新检查站。跌落只会回到最近检查站，已经获得的猫粮与服装会保留。

成功抵达终点后，庆祝动画结束便会自动回到起点。点击“从起点再出发”即可再次挑战；本轮检查站从起点重新记录，猫粮、猫咪外观、已购服装与通关记录全部保留。通关后退出并重新打开游戏，也会从起点开始。

部分平台放有猫粮包，每包获得 **3 份猫粮**。右上角显示当前可用数量。同一个猫粮包只能领取一次，返回检查站或重新启动游戏不会重复发放；整条路线共有 24 包，可以获得 72 份猫粮。

五只猫咪均可免费切换：橘猫“橘子”、白猫“奶糖”、灰猫“芝麻”、棕猫“可可”和布偶猫“布丁”。已购买的衣服可以重复穿脱，并可与任意猫咪搭配。

| 服装 | 猫粮价格 |
| --- | ---: |
| 薄荷围巾 | 8 |
| 莓果贝雷帽 | 12 |
| 星星披风 | 18 |
| 奶油王冠 | 25 |

购买成功会立即装备，重复点击已拥有的服装不会再次扣款。猫粮、累计收集量、已收集包、猫咪外观、已购服装、检查站、最高平台、通关记录和静音设置都会自动保存到 Godot 的 `user://paws_save_v1.json`。可以通过 Godot 编辑器的“项目 → 打开用户数据文件夹”找到存档。

## 窗口适配

基础画布为 1280 × 720，使用 `canvas_items` 与 `expand` 伸缩设置，原生窗口最小尺寸为 **640 × 480**。界面按实际宽高重新布局，衣橱会改变列数并提供滚动区域；竖向窗口同时调整界面比例、镜头距离与视野。宽屏、窄屏和竖屏都使用同一个游戏场景。

从 Godot 编辑器运行时，项目自带的“游戏窗口自适应”编辑器插件会把嵌入预览设为 **Stretch to Fit（拉伸以适应）**，避免只放大外层窗口、游戏画面仍固定为 1280 × 720。如果项目已在编辑器中打开，更新后重新打开一次项目即可加载插件；也可在游戏预览右上角菜单直接选择“拉伸以适应”。“项目 → 工具 → 恢复游戏窗口自适应”可以重新应用设置。此设置只针对当前项目。

这是一套桌面键鼠操作方案；竖屏布局可以使用，但目前没有触摸摇杆。

## 验证与截图

无界面玩法检查会自动按住空格，遍历全部 43 块平台，并检查复活、奖励去重、购买装备、五种猫咪切换、空中暂停与衣橱冻结、通关后继续。失败时进程会返回非零退出码。测试模式不读取或写入玩家存档。

```sh
godot --headless --path . -- --smoke-test
```

独立存档测试验证数据清理、奖励去重、非法输入、余额不足、重复购买与状态快照隔离。大部分检查使用 `persistent = false`，只操作内存；另有读写往返测试在系统缓存目录创建独立临时文件，结束后删除，不接触玩家存档。

```sh
godot --headless --path . --script res://tests/save_test.gd
```

截图模式需要可用的图形显示环境，**不能加 `--headless`**。它会输出标题画面、游戏画面、衣橱和多种窗口尺寸的 PNG，然后退出；截图同样使用独立的临时游戏状态。

```sh
mkdir -p captures
godot --path . -- --capture
```

截图保存在 `captures/`，可用于检查实际画面和窗口适配。

## 项目结构

| 文件 | 用途 |
| --- | --- |
| `scenes/main.tscn` | 项目启动场景 |
| `scripts/game.gd` | 螺旋路线、镜头、检查站、奖励、特效与集成检查 |
| `scripts/player.gd` | 移动、重力、辅助跳跃与弹跳 |
| `scripts/cat_visual.gd` | 五种猫咪、服装与动作 |
| `scripts/platform_factory.gd` | 扑克牌、糖、球、汉堡等程序化模型 |
| `scripts/mesh_batch.gd` | 合并静态网格、保留角色各部位动画，降低绘制开销 |
| `scripts/world_decor.gd` | 云朵、星星、棒棒糖与远景 |
| `scripts/game_ui.gd` | 标题、HUD、衣橱、暂停与响应式布局 |
| `scripts/save_data.gd` | 本地存档与购买规则 |
| `scripts/pickup.gd`、`scripts/sound.gd` | 猫粮包与程序合成音效 |
| `tests/save_test.gd` | 不接触玩家存档的独立测试 |

路线数量、平台间高度和螺旋角度集中在 `game.gd` 顶部；跳跃速度和重力位于 `player.gd`。调整路线距离时，应重新运行完整跳跃检查，确保辅助跳跃仍能到达下一块平台。服装价格定义在 `save_data.gd`，衣橱展示信息位于 `game_ui.gd`，修改价格时需要保持两者一致。

附带字体位于 `assets/fonts/NotoSansSC.ttf`，采用 SIL Open Font License 1.1；授权全文见 `assets/fonts/OFL.txt`。分发项目时请保留字体授权文件。
